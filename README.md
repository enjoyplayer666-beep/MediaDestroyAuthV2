# MediaDestroyAuth

Плагин авторизации/регистрации для сервера **MediaDestroy** (Paper 1.21.1, Java 21).

## Как это работает

1. **Новый вход / сессия истекла** — игрок замораживается (нельзя двигаться, ломать блоки,
   получать урон). Сверху висит боссбар с таймером на 120 секунд. Экран title/subtitle
   каждые 5 секунд переключается между:
   - «Введите пароль» / «Введите команду /l пароль»
   - «Или просто» / «напишите пароль в чат»
2. Пароль можно ввести **командой `/l <пароль>`** или **просто написав в чат**
   (сообщение перехватывается и не публикуется).
3. После ввода — экран «Проверка пароля...» с градиентным текстом.
   - Если игрок новый — пароль сохраняется (регистрация), и сразу идёт вход.
   - Если игрок уже зарегистрирован — пароль сверяется с хешем.
4. При успехе (обычный вход) — в чат уходит приветственное сообщение с ссылками
   сервера (без всплывающего тайтла).
5. Если игрок зашёл повторно **в течение часа** после последнего успешного входа —
   пароль вообще не спрашивается: сразу зелёный тайтл «С возвращением! / Ваша сессия
   сохранена!» + то же приветственное сообщение в чат.

Все тексты, цвета, ссылки и тайминги редактируются в `config.yml` после первого
запуска (файл создаётся в `plugins/MediaDestroyAuth/config.yml`).

Пароли хранятся хешированными (SHA-256 + случайная соль на игрока) в
`plugins/MediaDestroyAuth/players.yml` — plaintext-пароли нигде не сохраняются.

## Сборка

### Через GitHub (рекомендуется)

В репозитории уже есть workflow `.github/workflows/build.yml`. Просто запушь проект —
Actions соберёт `mediadestroy-auth.jar` и положит его в артефакты сборки (вкладка
**Actions → последний запуск → Artifacts**).

### Локально

```bash
mvn clean package
```

Готовый файл появится в `target/mediadestroy-auth.jar`. Кладёшь в `plugins/` на сервере.

## Регистрация, вход, смена пароля

- Кто ни разу не заходил — экраны «Регистрация / Придумайте пароль», пароль вводится два раза
  (`register.confirm-password`), длина `register.min-length`..`max-length`.
- После регистрации в чат — полное приветствие с «⚠ Ваш аккаунт уязвим!» (`welcome.register`),
  при следующих входах (по паролю и по сессии) — только верхний блок (`welcome.login`).
- Вход без пароля по сессии — только с того же IP, что и последний вход по паролю.

## Команды

- `/l <пароль>` — регистрация/вход (алиасы: `/login`, `/log`, `/reg`)
- `/changepassword <старый> <новый>` — смена пароля (алиасы: `/changepass`, `/cp`)
- `/mdauth reload` — перезагрузить `config.yml` (право `mediadestroyauth.admin`, по
  умолчанию у оператора)

## Важно

- Строка «Ваш аккаунт уязвим! Привяжите его... /link» в чате — это просто текст-заглушка
  под твой брендинг (как и было на скринах-референсах). Сама команда `/link` этим
  плагином **не реализована** — если нужна реальная привязка (Discord/2FA и т.п.),
  это отдельная функциональность, могу дописать отдельно.
- «Тёмный фон» на скринах-референсах — это ванильный title/subtitle поверх игры,
  плагин не подменяет фон полностью на чёрный (для настоящего полностью чёрного экрана
  нужен ресурспак или отдельная механика типа фейковой смены измерения — это вне
  задачи регистрации/логина).
